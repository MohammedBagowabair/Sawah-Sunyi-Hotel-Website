# Sawah Sunyi Ubud

Concept website for a fictional rice-terrace retreat in Ubud, Bali. Bilingual (English / Bahasa Indonesia), mobile-first, built with Vite, React, TypeScript and Tailwind CSS.

Photos are illustrative, from Wikimedia Commons under free licences; credits are listed in the site footer.

```bash
npm install
BASE_PATH=/Sawah-Sunyi-Hotel-Website/ PRELOAD_FONTS=fraunces-latin-wght-normal,manrope-latin npm run build
```
